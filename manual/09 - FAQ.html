FAQ

Quick answers, with a link to the page that has the full detail.

What does it actually produce, and what part is AI-generated? Deterministic structure: the file tree, per-file pages, cross-reference links, tables, the graph, and index.md. AI-generated: the prose descriptions (function/variable/summary text) — that's the only thing an LLM writes. See Determinism and LLM Phase.

Does it modify my source code? No. It only reads your sources and writes to project.output_dir (docs + meta/), project.data_dir (LLM records), and the .doc_cache file inside the output dir. Nothing in the tree is edited.

What's the difference between --no-llm and a normal run? --no-llm runs the entire pipeline with placeholder prose instead of LLM calls — real structure and links, no network, no token cost, and it never writes a record that a later full run would consider valid. A normal run asks the model for prose (reusing the cache where possible). Use --no-llm to iterate on structure fast; see First Run and Performance.

Why are some references orange or labeled (inferred)? Those are references the resolver could not tie to a single project definition. inferred = the name is defined exactly once project-wide but wasn't import-bound; orange = a builtin/stdlib or an out-of-project (external) name; an ambiguous name (defined 2+ times) gets no link at all and is recorded in diagnostics.json. The tool never guesses. See Symbols and Graph and Parsing and Resolution.

Why aren't my anonymous functions documented? They are in the graph and rendered, but excluded from the LLM phase by default to save tokens. Set documentation.include_anonymous_functions: true to have their prose generated too. See Config Reference.

Why doesn't a re-run hit the LLM cache for a symbol I didn't change? A record is only reused if its fingerprint matches. The fingerprint covers the symbol's source and its callers/callees, plus the model, base URL, prompt text, and the shaping settings. So changing a function's callers, changing the model, editing a prompt, or changing the relevant knobs invalidates the cached record. See Caching and Code Organization (tasks.py holds the fingerprint definitions).

What's the difference between --regenerate and --purge? Both delete the output/data dirs and start clean. --regenerate deletes and runs the pipeline; --purge deletes and exits. They are mutually exclusive. See CLI.

Does it only support the bundled languages? No — Lua, Python, C, C++ and CUDA are the bundled backends. The pipeline is language-agnostic: add a backend package (or --install URL an external one) that claims a new extension, and its files are documented. See Adding a Language and Backends.

Where is my API key, and what's it sent to? llm.api_key and llm.base_url are taken from the config, but the literal value "env" (or a missing value, the default) means "read it from a .env file" — searched project-root-first (next to main.py), then the config file's directory. If env is required but the key isn't found, the run stops with a clear message listing the paths it looked in. The key is only ever sent as a Bearer token to llm.base_url — the endpoint you configure (often a local model server). Nothing else leaves the machine except the LLM calls you initiate. See LLM Client.

My run ended with exit code 1. Is that a crash? No. Exit 1 means at least one LLM task failed and .doc_cache was not updated. Saved records are kept; rerunning resumes where it left off (failed tasks are retried). A hang or a Ctrl-C is different (Ctrl-C exits 130 and also keeps progress). See LLM Problems.

How do I preview the generated docs in a browser? python main.py --serve starts the web app (default 127.0.0.1:8123) with the docs, a file sidebar, a fuzzy search, and the interactive graph. See Web Server.

Can I document this tool itself? Yes — it's a Python project and its own backend documents it. configs/self.yaml builds doc_self/ locally (the generated docs and site/ are git-ignored). See Documenting kodama-docs Itself.

What license, and can the output be used to train a model? The code is MIT with an explicit clause excluding its use as AI/ML training data. Review LICENSE before reuse.
